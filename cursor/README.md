# Cursor

1. **Settings → Models → API Keys → OpenAI API Key**: paste your Ezkielyna key.
2. Turn on **Override OpenAI Base URL** and enter `https://api.ezkielyna.store/v1`, then click **Verify**.
3. **Add model**: type a name exactly as on [the model list](https://ezkielyna.store/models), for example `deepseek-v4.1-flash` or `glm-5.3`. Enable it and pick it in the chat panel.

The custom key is used for chat and agent requests with the models you add. Some Cursor features (for example Tab completion) keep using Cursor's own service.
