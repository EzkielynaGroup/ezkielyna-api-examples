# Cline, Roo Code, Kilo Code (VS Code)

All three accept an OpenAI-compatible provider.

| Field | Value |
|---|---|
| API Provider | **OpenAI Compatible** |
| Base URL | `https://api.ezkielyna.store/v1` |
| API Key | your Ezkielyna key (`sk-...`) |
| Model ID | e.g. `deepseek-v4.1-flash`, `glm-5.3` ([model list](https://ezkielyna.store/models)) |

Cline: click the Cline icon in the sidebar → gear icon (Settings) → fill the fields → save.

Notes:
- Claude and GPT models need a key in the **Auto** or **Premium** group.
- Agents resend the whole conversation on every step. Start a new task when you switch topics to keep input tokens (and cost) down.
- Every request shows up under **Log** at api.ezkielyna.store with its tokens and cost.
